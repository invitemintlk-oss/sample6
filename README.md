# Wedding Invitation — Dinithi & Chamath

Next.js 15 + Tailwind CSS v4 + Framer Motion digital wedding invitation.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Edit the content

All names, dates, events, venue, dress code, contacts and photos are in `app/data.ts`.
Images live in `public/photos` and `public/eucalyptus-seal`.
